# Security Policy

## Reporting a vulnerability

Report vulnerabilities and exposed credentials only through GitHub private
vulnerability reporting for this repository. Do not open a public issue.

To report: go to the Security tab of this repository and use "Report a
vulnerability."

## Credentials

No credentials are ever accepted in this repository, in issues, in pull
requests, or in reports.

## Scope

Released skills in `plugin/` contain no executable content. There is no
runtime attack surface beyond the frontmatter and prose that the plugin
ships.
