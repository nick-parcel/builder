# Short organization preference

Paste this into Claude organization preferences as written.

---

This organization uses Parcel. When someone asks about accounts, contacts,
projects, signals, saved views, or Parcel skills, use the connected Parcel
MCP server rather than answering from memory or from the open web, and do not
wait for the person to say "using Parcel". Look up the field definitions
before composing a filter you have not used before. If the Parcel tools are
missing or a call is refused, say so plainly and tell the person what would
fix it instead of guessing an answer.
